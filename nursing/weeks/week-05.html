0. この回の要点

講師は、健康総合科学科 地域看護学教室の松本先生(助教)です。文科Ⅲ類から健康総合科学科に進み、博士課程の途中で休学して、地域包括支援センターで保健師として働いた経験があります(p.3)。

一言でいうと
  • 地域で看護する=病院の外で暮らす個人・家族を支える(在宅看護、訪問看護、個別のケアマネジメント)。
  • 地域を看護する=社会・コミュニティ・集団を単位として、まちづくりや仕組みづくりをする(公衆衛生看護)。
  • 認知症で独り暮らしの人の困りごと(通帳の紛失、携帯の故障…)は、介護保険の範囲外で、家族がいなければ誰も担わない。「何でも屋」として対応し続けるには限界があるので、支え手を増やす仕組み(資源開発)が要る。

1. 保健師(p.5–11)

定義:保健師(保健師助産師看護師法)

厚生労働大臣の免許を受けて、保健師の名称を用いて、保健指導に従事することを業とする者。

  • 職場:主に自治体(保健所・市区町村)。多くの場合、保健師=地方自治体の公務員で、看護師的な側面と公務員的な側面をもつ。ほかに企業(産業保健師:ストレスチェックなど)や学校。
  • 仕事:乳幼児から高齢者まで、すべての住民が対象。生活習慣病予防の教室、たばこ対策の保健指導、乳幼児健康診査、家庭訪問、地域保健施策の企画・評価、まちづくり、災害対策。
  • なるには:看護系大学などで学び、看護師国家試験と保健師国家試験の両方に合格する(p.8)。
  • 数:就業者は看護師 約132万人、保健師 約6.7万人、助産師 約4.2万人、医師 約34万人(p.28 の図の数値。p.6 はクイズ形式)。
  • 名前の歴史:1993年までは女性限定で「保健婦」、その後男性もなれるようになり「保健士」、2002年から「保健師」に統合。
  • 男性看護師の割合(p.11):地域差が大きい(アフリカ地域 38.0%、ヨーロッパ 11.0% など)。ナイチンゲールが看護を「女性が家庭内で行うケアの延長」ととらえたことが、看護職のジェンダー観に影響している可能性がある。男性が看護を避けたり働きづらさを感じたりすることは、最終的には女性看護職の働きづらさにもつながりうる。

2. 介護保険と地域包括支援センター(p.12–29)

問い(p.13–14):自分の親の介護は誰がするか? 久々に実家に帰ると、薬の袋が山積み、コンロ周りが焦げている、冷蔵庫に卵がいっぱい、ちょっと変なにおい…。自分で手に負えそうになければ、とりあえず「地域包括支援センター」。

地域包括支援センター(p.15、p.29)

  • 介護保険法にもとづいて各市町村が設置する、高齢者・介護の相談窓口。
  • 職員は保健師、社会福祉士、主任介護支援専門員の3職種(東大で取れるのは保健師だけ)。
  • 4つの業務:① 介護予防ケアマネジメント・介護予防事業 ② 総合相談(要介護認定の申請も)③ 権利擁護(高齢者虐待の予防と対応)④ 地域の介護事業者・ケアマネジャーの支援。

介護保険制度(p.17–28)

時期介護はどうしていたか
かつて家族が手伝う、私費で人を雇う、養老施設に入る。国の福祉は、身寄りがない人・経済的に困窮している人に限られていた
1960年代〜老人福祉法で、特別養護老人ホームやホームヘルプサービスが制度化
その間高齢化率 5.7%(1960)→ 17.3%(2000)。「介護が必要になる」ことが特別でなくなる。財政危機と「社会的入院」、介護の長期化・重度化、家族の扶養機能の変化(女性への介護負担の偏り)
2000年介護保険制度がスタート=「介護の社会化」。高齢化率は 2022年に 29.1%
  • しくみ(p.19):保険者は市町村。財源は税金50%(国・都道府県・市町村)と保険料50%。加入者は第1号被保険者(65歳以上)と第2号被保険者(40〜64歳)。利用者の負担は1割(所得により2〜3割)。
  • 使い方(p.20):相談する(地域包括支援センター等)→ 介護事業者と契約する → 費用の一部を負担し、残りは保険から。医療保険と同じく「治療も契約」。
  • 好きなだけ使えるわけではない:要介護認定(主治医の意見書と面接調査をもとに7段階に分類)で、限度額と使えるサービスの種類が決まる。
  • サービスの例(p.25):訪問介護、訪問入浴、訪問看護、デイサービス、デイケア、福祉用具貸与、住宅改修、特別養護老人ホームなど。

ケアマネジメント(p.21–24)

定義:ケアマネジメント

個人が、各種のフォーマルなサービスやインフォーマルな支援を、個人を取り巻く状況に応じて最も適切に利用することで、有効にニードが満たされるよう、個人を支援する援助方法(平岡ほか『社会福祉学』)。

  • イメージ:「携帯が使えない」とき、ショップで契約? どの端末? そもそも何がしたい(LINE? 親に電話?)? 回線が切れていただけかも? → まずアセスメント(状況の把握)が必要。
  • 介護保険でケアマネジメントが要る理由(p.23):① 判断能力が十分でなく、サービスや事業者を選べない ② サービスの質に問題があっても、改善を求めにくい ③ 他人に頼ることを否定的に見る価値観の中で、要求を言い出しにくい ④ そもそも介護保険のサービスが複雑で、情報が足りない → 第三者がサービスを提案し、事業者と調整する。
  • 介護保険ではケアマネジャーが制度化されている:ニーズを把握し、ケアプランを作り、サービスを調整し、モニタリング・評価する。ただし、最終決定・契約する主体は本人。
  • 広義のケアマネジメントは、インフォーマルな支援(介護保険にもとづかないサービスや人々からの支援)の調整も含む。支援してくれる人・機関を開拓する資源開発も重要。

3. 地域で看護する:2つの事例(p.30–43)

事例1「携帯電話が使えない!」(一部改変)事例2「外鍵の家」
本人80代男性、初期の認知症、独居、歩行が不安定。介護保険で歩行器を利用(狭義のケアマネジメント)90代女性。家族から「お風呂に入らない」と相談。本人とはほとんど会話が成立しない。物が散らかった家
起きたこと銀行から電話(通帳・カードの紛失と再発行を繰り返す)→ 家でいろいろな通帳を発見。定期連絡の電話がつながらず、訪問すると携帯が故障していた。家族とは連絡がとれない。「向かいのマンションから銃で狙われている」という発言(精神疾患の見立て)。横断歩道で歩けなくなり、通りすがりの人に助けられる。自宅で転倒し救急搬送日中独居の間に本人が外出してしまうため、家族が玄関に外鍵(物を置いて開かないように)をしていた → 外鍵は身体的虐待として扱う
対応銀行・携帯ショップに同行して手続きを支援(暗証番号は覚えていた)。担当者に名刺を渡し、「心配なお客さんがいたら連絡を」と依頼=支える人を増やす(資源開発)。入院・老人保健施設に入所中に成年後見制度を申し立て、本人の希望もありグループホームに入所 → 落ち着いて生活緊急時(火事や急病)に助けを求められないことを理由に、外鍵はしないよう家族に伝える。階下の事業所にも、気づいたときの協力を依頼。要介護認定のために訪問診療を導入(十数年受診なし)。訪問介護(入浴介助):第三者からの働きかけだとうまくいくことも。慣れてきたらデイサービスで入浴 → 生活にリズムがつき外出も減った

何でも屋?(p.37):通帳を探す、再発行する、携帯を修理する…。これは誰がすべきことか? 介護保険の範囲ではない。家族がいれば多くの場合家族が担っている(だから問題が表に出ない)。

成年後見制度(p.41–43)

  • 法定後見:認知症・知的障害・精神障害などで判断能力が常に低下している人について、本人・家族・自治体などが申し立て、家庭裁判所が成年後見人等を選ぶ。後見人は、本人に代わって契約を結んだり、本人の契約を取り消したりできる。障害の程度に応じて後見>保佐>補助。前もって自分で後見人を選んでおく任意後見もある。
  • 後見人の仕事:財産管理(通帳の管理、収支、契約、不動産)と身上監護(入院・施設・介護サービスの契約と支払い)。実際の買い物や身体介護は後見人の仕事ではない。
  • 利用者は約23万人(認知症の高齢者は約600万人)。後見人の多くは第三者(弁護士・司法書士・社会福祉士・市民後見人など)=成年後見の社会化。社会保険ではないので完全自費(月2〜6万円程度)。2026年6月に民法改正法が成立し、2028年ごろから制度が見直される予定(類型の廃止、柔軟な運用)。
  • 家族が担ってきた経済扶養・意思決定・身体介護が、それぞれ年金保険・成年後見・介護保険として社会化された(税所真也『成年後見の社会学』の図)。

4. 地域を看護する(p.44–54)

地域で看護する地域を看護する
地域に住む(医療機関以外の場所で)個人・家族に対する看護。≒ 在宅看護・訪問看護・個別のケアマネジメント社会・コミュニティ・組織・集団を対象として(まとまりとして捉えて)看護を行う。まちづくり・地域づくり・仕組みづくり。≒ 公衆衛生看護

何でも屋としてその場しのぎの対応を繰り返すには限界がある。保健師の強みは、両者を別々にせず、個別支援で見つかったニーズや経験をもとに仕組みを作っていくこと、そして事後対応でなく上流での予防的介入をすること。

支え手を増やす(p.46–48)

  • 成年後見制度はまだ使い勝手がよくない。認知症の人は約600万人(2020年推計)から約800万人(2040年推計)へ。「家族」が増える・役割を増すことはなさそう。
  • では誰が生活を支える? 友人・近隣住民、行政・医療介護の専門職、通りすがりの人、生活の中で接する企業(不動産管理、金融機関、携帯ショップ…)、ロボット・テクノロジー、自分、既にある資源の活用。
  • 講師の研究テーマ:コンビニなどで働く人に認知症について教え、何かあったときの手助け・連絡をしてもらう。道迷いや外での急変には、通りすがりの人の支援も不可欠。
  • 認知症サポーター:2005年開始、2024年までに延べ1500万人以上が講座を受講。国の認知症施策推進大綱(2019)も、小売業・金融機関・公共交通機関の従業員などへの養成講座の拡大を掲げている。
  • 社会福祉の一般的機能(岡村重夫『社会福祉原論』):評価的・調整的・送致的・開発的・保護的機能。
  • ケアマネジャーの業務の整理(厚労省の検討会、2024):法定業務のほか、郵便の受け取り・代筆、家事支援、預貯金の引き出し、徘徊時の捜索、死後事務などの「保険外」の業務は、他の機関や地域の資源につなぐべきものとされている。

5. 研究:支援行動を阻むもの・促すもの(p.55–60)

コンビニ従業員向けの認知症 e ラーニング(約45分:講義動画、クイズ、店での対応を想定したシミュレーション、認知症の人のインタビュー映像、コンビニでの買い物が認知症の人の生活に役立っていることの紹介)を作り、効果をRCT(ランダム化比較試験)で検証した。

手がかりにした理論:

  • 傍観者効果(Darley と Latané 1968):人が助けるまでには「緊急事態 → 気づく → 緊急の対応が要ると解釈する → 自分の責任と認識する → 適切な方法を知っている → 支援する」という段階がある。「みんな平気そうだから大丈夫だろう」(多元的無知)や「誰かがやるだろう」(責任の拡散)が途中で妨げる。
  • スティグマ(ゴフマン 1963):偏見(感情)・ステレオタイプ(認知)・差別(行動)が、反射的な回避や「危険だ」という判断を生み、支援行動を妨げる。教育と接触(接触仮説、オールポート 1954)で減らせる。
  • 関係的職務設計(Grant 2007):自分の仕事が相手の役に立っていると感じると、向社会的な動機が高まり、援助行動につながる。

結果(p.60、Matsumoto ら 2022):介入群では、1か月後に認知症の知識と援助行動が上がり、4か月後もおおむね保たれていた(グラフの読み取り)。

レポート課題(p.31、p.62)

レポート課題

本日紹介する事例のいずれかを選び、どのような対応が可能かを考え、記述する。

  • 個別事例に対する対応でも、同様の事例を予防する/制度的に対応するための対応でもよい。
  • 行政、民間事業者・企業、近隣住民、通りすがりの人、テクノロジーなど、どのような形・立場でもよい(家族による支援は除く)。

考えた対応について、実現するための課題(どのようなハードルがあるか、どのような悪影響・副作用が考えられるか)も考察する。
