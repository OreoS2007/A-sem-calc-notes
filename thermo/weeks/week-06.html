0. この回の全体像 板書 p.7

前回、Kelvin と Clausius の原理から、「熱を全部仕事に変えることはできない」ことが分かりました。では、熱機関の熱効率の上限はいくらなのか。この回は、その問いに、数式で答えます。そして、その答えが、物質によらない温度(熱力学温度)の定義につながる、という、熱力学の核心を学びます。

この回のゴール

① 2つの熱源の間で働く、どんなサイクルの熱効率 $\eta'$ も、Carnot サイクルの熱効率 $\eta_C$ 以下。$\eta'\lt\eta_C$ なら不可逆。
② 理想気体の Carnot サイクルの熱効率 $\eta_C=1-\dfrac{T_2}{T_1}$。
③ Carnot サイクルが熱源とやりとりする熱の比 $\dfrac{Q_2}{Q_1}$ は、作業物質にも、仕事の大きさにもよらず、熱源の温度だけで決まる。ここから、物質によらない温度(熱力学温度、Kelvin の温度)$T$ が $\dfrac{Q_2}{Q_1}=\dfrac{T_2}{T_1}$ で定義できる($T\gt0$)。
④ Carnot サイクルでは $\dfrac{Q_1}{T_1}=\dfrac{Q_2}{T_2}$(換算熱が等しい)。次回の Clausius の不等式への入口。

1. 準備:基礎の確認

1.1 熱機関と熱効率

基礎:$\eta=W/Q_1=1-Q_2/Q_1$ → 詳しい解説

熱機関が、高温熱源から熱 $Q_1$ をもらい、仕事 $W$ をして、低温熱源に熱 $Q_2$ を捨てる(1周)。第1法則 $Q_1=W+Q_2$。熱効率 $\eta=\dfrac{W}{Q_1}=1-\dfrac{Q_2}{Q_1}$。第5回の板書では、吸収する熱を $Q$、捨てる熱を $Q'$ と書いた。この回の板書は、$Q_1,Q_2$($T_1,T_2$ の熱源とやりとりする熱)の書き方も使う。

1.2 理想気体の等温変化・断熱変化

基礎:$PV=nRT$、$PV^\gamma=$ 一定、$\Delta U=C_V\Delta T$ → 詳しい解説

理想気体では、等温変化($T$ 一定):$\Delta U=0$、気体が吸う熱 $Q=$ 気体が外にする仕事 $=nRT\log\dfrac{V_B}{V_A}$。断熱変化(準静的):$Q=0$、$PV^\gamma=$ 一定、$TV^{\gamma-1}=$ 一定、外からされる仕事 $W=\Delta U=C_V\Delta T$(第3回、第4回)。

2. 3.6 Carnot サイクルの熱効率:上限であること 板書 p.7

板書:「3.6 Carnot サイクルの熱効率。※ 2つの熱源と熱のやりとりをするサイクル C′ の熱効率 $\eta'$ は、$\eta'\le\eta_C$ である($\eta_C$:Carnot サイクルの熱効率)。かつ、$\eta'\lt\eta_C$ となるサイクルは、不可逆サイクルである。」

Carnot サイクルの熱効率の定理

同じ2つの熱源 $T_1\gt T_2$ の間で働く、任意のサイクル C′ の熱効率 $\eta'$ は、Carnot サイクルの熱効率 $\eta_C$ 以下:$\eta'\le\eta_C$。さらに、$\eta'\lt\eta_C$ であるようなサイクルは、不可逆。

つまり、Carnot サイクルは、2つの熱源の間で、最も効率のよいサイクルです。

証明($\eta'\le\eta_C$)

板書:「証明。サイクル C′ の熱効率 $\eta'$ が、$\eta_C$ より大きいとする。Carnot サイクル C は、高温から Q をもらって、仕事 W をする。サイクル C′ は、高温から熱 Q をもらい、仕事 $W'=W+\Delta W$($\Delta W\gt0$)。→ $Q'-Q''=\Delta W$ を熱源からもらい、$\Delta W$ の仕事をする。⇒ Kelvin に反する。」

  1. 背理法:C′ の熱効率 $\eta'$ が、C の熱効率 $\eta_C$ より大きいと仮定する。
  2. C は、高温熱源から熱 $Q$ をもらって、仕事 $W=\eta_CQ$ をする(低温熱源に $Q'=Q-W$ を捨てる)。
  3. C′ も、高温熱源から同じ熱 $Q$ をもらうとする。$\eta'\gt\eta_C$ だから、仕事は $W'=\eta'Q=W+\Delta W$($\Delta W\gt0$)。低温熱源へは、$Q-W'=Q'-\Delta W$ を捨てる。
  4. C′ を正の向きに回し、その仕事 $W'$ のうち $W$ を使って、C を逆向きに回す(逆 Carnot サイクルは、仕事 $W$ を使って、低温から $Q'$ を、高温へ $Q$ を運ぶ:第5回)。残りの $\Delta W$ は、外に出す。
  5. 高温熱源:C′ に $Q$ を渡し、逆 C から $Q$ をもらう:正味 0。低温熱源:C′ から $Q'-\Delta W$ をもらい、逆 C に $Q'$ を渡す:正味 $\Delta W$ を失う。外に出る仕事:$\Delta W$。
  6. 全体として、低温の1つの熱源だけから熱 $\Delta W$ をとって、同じ大きさの仕事 $\Delta W$ を外に出す。Kelvin の原理に反する。よって、$\eta'\gt\eta_C$ は不可能。$\eta'\le\eta_C$。
板書にない補足:$\eta'\lt\eta_C$ なら不可逆である理由

板書の定理の後半、「$\eta'\lt\eta_C$ なら C′ は不可逆」は、次のように示せます。もし、C′ が可逆だったとすると、C′ も、逆向きに回せる。そこで、上の証明の C と C′ の役割を入れかえる:C′ を逆に、C を正に回すと、$\eta_C\le\eta'$ が導かれる(同じ議論)。すると、$\eta'\le\eta_C$ と合わせて、$\eta'=\eta_C$。つまり、可逆なサイクルの熱効率は、必ず $\eta_C$ に等しい。ゆえに、$\eta'\lt\eta_C$ のサイクルは、可逆ではありえない(不可逆)。熱伝導や摩擦など、不可逆な過程が混ざると、効率が下がる、ということです。

板書の次の行:「※ Carnot サイクルの性質は、作業物質に依存しない。→ ゴム・酸素・(他の物質)でもよい。」

これも、上の定理から出ます。作業物質が違う、2つの Carnot サイクル C、C̃ を考えると、どちらも可逆なので、(補足の結果から)熱効率は、どちらも「可逆なサイクルの熱効率」で、等しい。したがって、$\eta_C$ は、作業物質によらず、2つの熱源の温度だけで決まる。これが、次節の、物質によらない温度の土台になります。

3. 理想気体の Carnot サイクル:$\eta_C=1-T_2/T_1$ 板書 p.7

作業物質が何でもよいので、いちばん計算しやすい理想気体で、$\eta_C$ を具体的に計算します。(板書:「◎ 理想気体の Carnot サイクル」。$P$–$V$ 図で A→B→C→D、$T_1\gt T_2$。)

以下、「$W$」は、各過程で、外から気体にされた仕事(符号つき)です。

① A→B(準静的等温過程)

板書:「① A→B(準静的等温過程)$PV=nRT$、$\left(\dfrac{\partial U}{\partial V}\right)_T=0$。$W_{A\to B}=\int_{V_A}^{V_B}(-P)\,dV=-\int_{V_A}^{V_B}\dfrac{nRT_1}{V}dV=-nRT_1\log\dfrac{V_B}{V_A}=-Q_{A\to B}=-Q_1$。」

等温($T_1$)なので $\Delta U=0$(理想気体では $U$ は温度だけで決まる)。第1法則から、吸収した熱 $Q_{A\to B}=-W_{A\to B}$。これを $Q_1$ と書く(気体が受け取る熱): $$Q_1=nRT_1\log\frac{V_B}{V_A}\ \gt0\quad(V_B\gt V_A).$$

② B→C(準静的断熱過程)

板書:「② B→C(準静的断熱過程)$Q_{B\to C}=0$。$P_BV_B^\gamma=PV^\gamma$($\gamma=C_P/C_V$)。$W_{B\to C}=-\int_{V_B}^{V_C}\dfrac{P_BV_B^\gamma}{V^\gamma}dV=\dfrac{R}{\gamma-1}(T_2-T_1)$。」

断熱($Q=0$)では、$PV^\gamma=P_BV_B^\gamma$($=$ 一定)。積分すると、 $$W_{B\to C}=-P_BV_B^\gamma\int_{V_B}^{V_C}V^{-\gamma}dV=-P_BV_B^\gamma\cdot\frac{V_C^{1-\gamma}-V_B^{1-\gamma}}{1-\gamma}=\frac{P_CV_C-P_BV_B}{\gamma-1}=\frac{nR(T_2-T_1)}{\gamma-1}.$$ (板書は $n=1$ mol として $R$。)温度が $T_1\to T_2$ に下がるので、$W_{B\to C}\lt0$(気体は、内部エネルギーを使って、外に仕事をする)。これは、$\Delta U=C_V(T_2-T_1)=\dfrac{nR}{\gamma-1}(T_2-T_1)$(第4回)と、一致します。

③ C→D(準静的等温過程)と、④ D→A(断熱)

板書:「③ C→D 等温過程:$W_{C\to D}=-nRT_2\log\dfrac{V_D}{V_C}=-Q_{C\to D}=Q_2$。④ D→A 断熱過程:$W_{D\to A}=\dfrac{R}{\gamma-1}(T_1-T_2)$。」

  • ③ 等温($T_2$)の圧縮($V_D\lt V_C$):$W_{C\to D}=-nRT_2\log\dfrac{V_D}{V_C}=nRT_2\log\dfrac{V_C}{V_D}\gt0$。このとき、気体は熱を放出($Q_{C\to D}\lt0$)。放出した熱の大きさを $Q_2$ と書くと、$W_{C\to D}=-Q_{C\to D}=Q_2$: $$Q_2=nRT_2\log\frac{V_C}{V_D}\ \gt0.$$
  • ④ 断熱:$W_{D\to A}=\dfrac{nR}{\gamma-1}(T_1-T_2)$。②と、符号だけ違う。

熱効率

板書:「$\eta_C=\dfrac WQ_1=\dfrac{Q_1-Q_2}{Q_1}=1-\dfrac{RT_2\log\frac{V_C}{V_D}}{RT_1\log\frac{V_B}{V_A}}=1-\dfrac{T_2}{T_1}$。等温過程:$RT_1=P_AV_A=P_BV_B$、$RT_2=P_CV_C=P_DV_D$。断熱過程:$P_BV_B^\gamma=P_CV_C^\gamma$、$P_DV_D^\gamma=P_AV_A^\gamma$ ⇒ $\dfrac{V_C}{V_D}=\dfrac{V_B}{V_A}$。」

  1. 1周の、外にする仕事 $W=-(W_{A\to B}+W_{B\to C}+W_{C\to D}+W_{D\to A})$。② と ④ は打ち消しあうので、$W=Q_1-Q_2$。
  2. 熱効率:$\eta_C=\dfrac{W}{Q_1}=1-\dfrac{Q_2}{Q_1}=1-\dfrac{T_2\log(V_C/V_D)}{T_1\log(V_B/V_A)}$。
  3. 体積の比を比べる。② と ④ の断熱関係を、辺々割ると:$\dfrac{P_BV_B^\gamma}{P_AV_A^\gamma}=\dfrac{P_CV_C^\gamma}{P_DV_D^\gamma}$。等温過程より $P_BV_B=P_AV_A$、$P_CV_C=P_DV_D$ なので、$\left(\dfrac{V_B}{V_A}\right)^{\gamma-1}=\left(\dfrac{V_C}{V_D}\right)^{\gamma-1}$、つまり、 $$\frac{V_B}{V_A}=\frac{V_C}{V_D}.$$
  4. 対数の中身が等しいので、約分できて、$\eta_C=1-\dfrac{T_2}{T_1}$。
理想気体の Carnot サイクル

$$\eta_C=1-\frac{T_2}{T_1},\qquad\frac{Q_2}{Q_1}=\frac{T_2}{T_1}.$$ 熱効率は、温度比だけで決まる。

ここの $T$ は、理想気体の状態方程式 $PV=nRT$ で決まる温度(経験温度の一種)です。次節で、この $T$ が、物質によらない「熱力学温度」と一致する、ことが分かります。

4. 3.7 熱力学的温度 板書 p.7

板書:「3.7 熱力学的温度。※ Carnot サイクルの熱効率は、作業物質に依らない ⇒ 温度を決める。」

水銀温度計やガス温度計で決める経験温度は、物質の性質に頼っています(第1回)。ところが、いま、Carnot サイクルの熱効率が、作業物質によらず、熱源の温度だけで決まることが分かりました。これを使えば、物質に依存しない温度の目盛りが作れるはずです。

(a) 同じ仕事を取り出す Carnot サイクルは、同じ熱をやりとりする

板書:「(a) Carnot サイクル C と C′ を用いて、共通の仕事 W をとりだす。$Q_1=Q_1'$、$Q_2=Q_2'$。($Q_1\lt Q_1'$、$Q_2\gt Q_2'$ ← これらはダメ。)⇒ Carnot サイクルの性質は、仕事と熱源の温度で決まる。」

同じ2つの熱源($T_1,T_2$)の間で働く、2つの Carnot サイクル C、C′(作業物質が違ってもよい)が、同じ仕事 $W$ を出すとします。C は熱 $Q_1$ をもらい $Q_2$ を捨て、C′ は $Q_1'$ をもらい $Q_2'$ を捨てる。$Q_1=W+Q_2$、$Q_1'=W+Q_2'$。

もし、$Q_1\lt Q_1'$ だったとすると、$Q_2=Q_1-W\lt Q_1'-W=Q_2'$。ここで、C を正に、C′ を逆に回すと、低温熱源は $Q_2'-Q_2\gt0$ を失い、高温熱源は $Q_1'-Q_1\gt0$ を得て、仕事は $W-W=0$:仕事なしに、低温から高温へ熱が移る。Clausius の原理に反する(板書の「これらはダメ」)。$Q_1\gt Q_1'$ のときは、C と C′ の役割を逆にすれば、同じ。よって、$Q_1=Q_1'$、$Q_2=Q_2'$。Carnot サイクルが、熱源とやりとりする熱は、出す仕事と、熱源の温度で、決まる。

(b) サイクルを $n$ 回まわす:熱の比は、仕事によらない

板書:「(b) サイクルを $n$ 回まわす。1回目:$Q_1$、$W$ (C)。$Q_1'$、$W$ (C′)。2回目:$Q_1$、$2W$。⋮ $n$ 回目:$nQ_1$、$nW$。$\dfrac{Q_2}{Q_1}=\dfrac{nQ_2}{nQ_1}$。仕事に依らず熱の比は一定。→ Carnot サイクルと、熱のやりとりをする熱源の種類によらず、熱の比は、普遍的に決まっている。」

C を $n$ 回まわすと、熱 $nQ_1$ をもらい、仕事 $nW$ を出し、熱 $nQ_2$ を捨てる。この「$n$ 回分」は、仕事 $nW$ を出す Carnot サイクルとみなせるので、(a) から、仕事 $nW$ を出すどの Carnot サイクルも、$nQ_1$ をもらい $nQ_2$ を捨てる。熱の比は、 $$\frac{Q_2}{Q_1}=\frac{nQ_2}{nQ_1}$$ と、$n$(つまり出す仕事の大きさ)によらない。結局、2つの熱源の間で動く Carnot サイクルの熱の比 $Q_2/Q_1$ は、作業物質にも、仕事の大きさにもよらず、2つの熱源の温度だけで決まる。

(c) 3つの熱源と、比の関数 $f$

熱源の温度を、何か1つの経験温度(温度計の目盛り)で表して $\theta_1,\theta_2$ としましょう(板書では、これを $T_1,T_2$ と書いている)。上の結果は、熱の比が、2つの温度の関数であること、 $$\frac{Q_2}{Q_1}=f(T_2,T_1)$$ を意味します($f$ は、物質によらない、普遍的な関数)。

板書:「◎ 3つの熱源と熱のやりとりをする Carnot サイクル。$\dfrac{Q_2}{Q_1}=f(T_2,T_1)=\dfrac{Q_2}{Q_0}\cdot\dfrac{Q_0}{Q_1}=\dfrac{f(T_2,T_0)}{f(T_1,T_0)}$。⇒ $\boxed{f(T_2,T_1)\,f(T_1,T_0)=f(T_2,T_0)}$。」

  1. 3つの熱源 $T_0,T_1,T_2$ を用意する。$T_0$ と $T_1$ の間の Carnot サイクルを回して、熱 $Q_0$ と $Q_1$ をやりとりする($Q_1/Q_0=f(T_1,T_0)$)。
  2. $T_1$ と $T_2$ の間の Carnot サイクルを回して、$T_1$ から、さきほどと同じ熱 $Q_1$ をやりとりする(サイズを合わせる)。$T_2$ との熱は $Q_2$($Q_2/Q_1=f(T_2,T_1)$)。
  3. 2つをあわせると、$T_1$ との熱のやりとりは打ち消しあって、全体は、$T_0$ と $T_2$ だけと熱 $Q_0$、$Q_2$ をやりとりする可逆サイクル。(前節の結果:可逆なサイクルは、同じ熱効率をもつ、から、これも、$T_0$–$T_2$ の Carnot サイクルと同じ関数 $f$ に従う。)$Q_2/Q_0=f(T_2,T_0)$。
  4. $\dfrac{Q_2}{Q_0}=\dfrac{Q_2}{Q_1}\cdot\dfrac{Q_1}{Q_0}$ から、$f(T_2,T_0)=f(T_2,T_1)\,f(T_1,T_0)$。

板書:「$f(x,y)=F(x)G(y)$ と、変数分離型を仮定。$F(T_2)G(T_1)F(T_1)G(T_0)=F(T_2)G(T_0)$。⇒ $F(T_1)G(T_1)=1$、$F(x)=\dfrac1{G(x)}$。⇒ $\dfrac{Q_2}{Q_1}=f(T_2,T_1)=F(T_2)G(T_1)=\dfrac{F(T_2)}{F(T_1)}$ ⇒ $F(T)=aT$:Kelvin の温度。」

関係式 $f(T_2,T_1)f(T_1,T_0)=f(T_2,T_0)$ を満たす関数 $f$ は、「$F(x)/F(y)$」の形をしている、と考えます。板書は、$f(x,y)=F(x)G(y)$ と仮定して、これを代入し、$F(T_2)G(T_1)F(T_1)G(T_0)=F(T_2)G(T_0)$。両辺を $F(T_2)G(T_0)$ で割ると $F(T_1)G(T_1)=1$。つまり $G=1/F$: $$\frac{Q_2}{Q_1}=\frac{F(T_2)}{F(T_1)}.$$

板書にない補足:「変数分離型の仮定」は、仮定しなくても出る

$f(T_2,T_0)=f(T_2,T_1)f(T_1,T_0)$ は、$T_0$ を基準の温度として固定すると、$f(T_2,T_1)=\dfrac{f(T_2,T_0)}{f(T_1,T_0)}$。ここで $F(T):=f(T,T_0)$ と定義すれば、そのまま $f(T_2,T_1)=\dfrac{F(T_2)}{F(T_1)}$ になります。変数分離型は、仮定でなく、関係式から自動的に出る形です。

熱力学温度(Kelvin の温度)の定義

$\dfrac{F(T_2)}{F(T_1)}$ を、そのまま、新しい温度の比と決める。すなわち、温度 $T$ を、$T=aF$($a$ は、目盛りの大きさを決める定数)で定義すると、 $$\frac{Q_2}{Q_1}=\frac{T_2}{T_1}.$$ 2つの熱源の間の Carnot サイクルが、やりとりする熱の比が、熱源の温度の比に等しい。これが熱力学温度 $T$ [K]。

この定義は、物質の性質を、一切使っていません(熱力学の法則だけから決まる)。経験温度が、物質ごとに少しずつ違うのに対して、これは普遍的な温度です。目盛りの大きさ(定数 $a$)は、次で決めます。

(d) 目盛りの決め方:氷点と沸点

板書:「※ 1気圧の氷点(融点)と沸点で、Carnot サイクル。$\dfrac{Q_2(\text{氷点})}{Q_1(\text{沸点})}=\dfrac{T_0}{T_0+100}$ ⇒ $T_0=273.15\,[\mathrm K]$。経験温度 → 熱 → エネルギー。」

1気圧の水の氷点と沸点の間の幅を、$100$ K(セルシウス温度の $100\,{}^\circ\mathrm C$ と同じ幅)にとります。氷点の熱力学温度を $T_0$ とすると、沸点は $T_0+100$。この2つの熱源で、Carnot サイクルを回して、熱の比を測ると、$\dfrac{Q_2}{Q_1}=\dfrac{T_0}{T_0+100}$。実験の結果から、$T_0=\dfrac{100\,r}{1-r}$($r=Q_2/Q_1$)を計算すると、$T_0=273.15\ \mathrm K$。これが、第1回の $T\,[\mathrm K]=t\,[^\circ\mathrm C]+273.15$ の根拠です。

(板書の右の、「経験温度 → 熱 → エネルギー」は、「温度の決め方が、物質の性質(経験温度)から、熱のやりとり(Carnot サイクル)へ、さらに、エネルギーの概念へ、移った」という流れを示す、メモと読みました。)

5. 熱力学温度の非負性と、換算熱 板書 p.7

板書:「◎ 熱力学温度の非負性。$0\lt\eta=1-\dfrac{T_2}{T_1}\lt1$ ∴ $T_1,T_2\gt0$。Carnot サイクルは正の仕事をする ← 第二法則。$1\gt\dfrac{T_2}{T_1}$、$T_1\gt0$。」

熱力学温度 $T$ が、正であることを示します。Carnot サイクルが正の仕事をする($W\gt0$、第5回の性質1)なら、$Q_1\gt Q_2$。また、$Q_2\gt0$(もし $Q_2=0$ なら、Kelvin の原理に反する)。したがって、 $$0\lt\eta=1-\frac{Q_2}{Q_1}=1-\frac{T_2}{T_1}\lt1\ \Longrightarrow\ 0\lt\frac{T_2}{T_1}\lt1.$$ 温度の比が、正で、1より小さい。熱力学温度の符号を、「高温熱源 $T_1\gt0$」にとると、低温熱源の $T_2$ も正で、$T_1\gt T_2\gt0$。つまり、熱力学温度は、正の値しかとらない(絶対零度より低い温度は、ない)。$\eta=1-\dfrac{T_2}{T_1}=1$ になるのは、$T_2=0$ のときだけで、これには到達できません。

Clausius の不等式への入口:換算熱

板書:「Clausius の不等式。Carnot サイクル:$\dfrac{Q_2}{Q_1}=\dfrac{T_2}{T_1}$ ⇒ $\dfrac{Q_2}{T_2}=\dfrac{Q_1}{T_1}$ ←換算熱。※ 熱源が2つ以上あるときの換算熱の性質。熱の正の向きをサイクルに入る向きにする。$\dfrac{Q_1}{T_1}+\dfrac{Q_2}{T_2}\le0$。」

熱 $Q$ を、そのときの熱源の温度 $T$ で割った量 $\dfrac QT$ を、換算熱といいます。Carnot サイクルでは、高温で受け取る熱の換算熱 $\dfrac{Q_1}{T_1}$ と、低温で捨てる熱の換算熱 $\dfrac{Q_2}{T_2}$ が、等しい: $$\frac{Q_1}{T_1}=\frac{Q_2}{T_2}\qquad\text{(Carnot サイクル)}.$$ ここで、熱の符号を、サイクル(作業物質)に入る向きを正と決め直すと、低温で捨てる熱は負になるので、$\dfrac{Q_1}{T_1}+\dfrac{Q_2}{T_2}=0$(Carnot サイクル)。一般のサイクル(不可逆なものを含む)では、$\le0$ になる。これが Clausius の不等式で、次回の主題、エントロピーの出発点です。

6. 具体例で練習(板書にない補足) 補足

問題 A:Carnot 効率の計算

高温熱源 $T_1=500\ \mathrm K$、低温熱源 $T_2=300\ \mathrm K$ の間で、Carnot サイクルを回す。(i) 熱効率 $\eta_C$ は。(ii) 高温熱源から $Q_1=1000\ \mathrm J$ をもらうとき、仕事 $W$ と捨てる熱 $Q_2$ は。

解答

(i) $\eta_C=1-\dfrac{300}{500}=0.4$。(ii) $W=\eta_CQ_1=400\ \mathrm J$、$Q_2=Q_1-W=600\ \mathrm J$($=Q_1\dfrac{T_2}{T_1}=600\ \mathrm J$ ✓)。

問題 B:現実のエンジンと、上限

自動車のエンジンの燃焼ガスの温度を $T_1=1000\ \mathrm K$、外気を $T_2=300\ \mathrm K$ とする。熱効率の上限を求めよ。実際のエンジンの熱効率は、約 0.3 である。この差は、何を意味するか。

解答

$\eta_C=1-\dfrac{300}{1000}=0.7$。実際の約 0.3 との差は、摩擦、有限の温度差での熱伝導、燃焼の不可逆性など、不可逆な過程で失われる分(定理:$\eta'\lt\eta_C$ なら不可逆)。上限 0.7 は、これ以上は、どんな工夫でも、達成できない限界。

問題 C:理想気体の Carnot サイクルの数値

$n=1\ \mathrm{mol}$ の理想気体で、$T_1=500\ \mathrm K$、$T_2=300\ \mathrm K$、$V_A=1.0\ \mathrm L$、$V_B=2.0\ \mathrm L$ の Carnot サイクルを回す。$Q_1$、$Q_2$、$W$、$\eta$ を求めよ。$R=8.31\ \mathrm{J/(mol\cdot K)}$。

解答

$Q_1=nRT_1\log\dfrac{V_B}{V_A}=8.31\times500\times\log2=4155\times0.693=2.88\times10^3\ \mathrm J$。断熱過程の関係から $\dfrac{V_C}{V_D}=\dfrac{V_B}{V_A}=2$ なので、$Q_2=nRT_2\log2=8.31\times300\times0.693=1.73\times10^3\ \mathrm J$。$W=Q_1-Q_2=1.15\times10^3\ \mathrm J$。$\eta=\dfrac{W}{Q_1}=0.40=1-\dfrac{300}{500}$ ✓。

問題 D:氷点・沸点の熱の比から $T_0$ を求める

1気圧の水の氷点と沸点を熱源にして、Carnot サイクルを回したら、$\dfrac{Q_2}{Q_1}=0.7320$ だった。氷点の熱力学温度 $T_0$ を求めよ。

解答

$\dfrac{T_0}{T_0+100}=r$ より $T_0=\dfrac{100r}{1-r}=\dfrac{73.20}{0.2680}=273.1\ \mathrm K$。

問題 E:ヒートポンプ(逆 Carnot サイクル)で暖房する

外気 $0\,{}^\circ\mathrm C$($273\ \mathrm K$)から熱をくみ上げて、室内 $20\,{}^\circ\mathrm C$($293\ \mathrm K$)を暖める。理想的な(逆 Carnot の)ヒートポンプで、電気(仕事)$W=1\ \mathrm{kJ}$ を使ったとき、室内に供給できる熱 $Q_1$ は、最大いくらか。

解答

逆 Carnot サイクルでは、同じ大きさの熱・仕事が、向きだけ逆。正サイクルの効率 $\eta_C=1-\dfrac{T_2}{T_1}=\dfrac{W}{Q_1}$ より、$Q_1=\dfrac{W}{\eta_C}=\dfrac{W\,T_1}{T_1-T_2}=1\ \mathrm{kJ}\times\dfrac{293}{20}\approx14.7\ \mathrm{kJ}$。電気ヒーター(1 kJ の電気が 1 kJ の熱)に比べて、約15倍。温度差が小さいほど、ヒートポンプは有利。

7. まとめ(この回で覚えること)

  • 2つの熱源の間のどんなサイクルも、熱効率 $\eta'\le\eta_C$(Kelvin の原理から)。可逆なサイクルの効率は $\eta_C$ に等しい。$\eta'\lt\eta_C$ なら不可逆。$\eta_C$ は、作業物質によらない。
  • 理想気体の Carnot サイクル:$Q_1=nRT_1\log\frac{V_B}{V_A}$、$Q_2=nRT_2\log\frac{V_C}{V_D}$、$\frac{V_B}{V_A}=\frac{V_C}{V_D}$、$\eta_C=1-\dfrac{T_2}{T_1}$。
  • Carnot サイクルが熱源とやりとりする熱の比は、熱源の温度だけで決まる($f(T_2,T_1)$)。3つの熱源の考察から、$f(T_2,T_1)f(T_1,T_0)=f(T_2,T_0)$ ⇒ $f=\dfrac{F(T_2)}{F(T_1)}$。
  • 熱力学温度(Kelvin の温度):$\dfrac{Q_2}{Q_1}=\dfrac{T_2}{T_1}$ で定義。物質によらない。氷点と沸点の熱の比から $T_0=273.15\ \mathrm K$。$T\gt0$。
  • Carnot サイクルでは、換算熱が等しい:$\dfrac{Q_1}{T_1}=\dfrac{Q_2}{T_2}$。入る熱を正にとると、$\dfrac{Q_1}{T_1}+\dfrac{Q_2}{T_2}=0$(一般のサイクルでは $\le0$:次回)。

8. この回のノートについてのメモ

板書は手書きの画像です。画像の順に p.7(下端から、次の p.8 へ続く)としました。板書の画像は、このサイトには載せていません。黄色の枠、基礎ページの内容、練習問題と解答は、Claude が書き足したもので、板書にはありません。

  1. $n$ の扱い(p.7):板書の理想気体の Carnot サイクルは、$n=1$ mol として $R$ と書かれている行と、$nR$ の行が混ざっています。本文は $nR$ で統一しました。
  2. $Q$ の添字(p.7):板書は、$Q_1,Q_2$、$Q$、$Q'$ を混ぜて使っています(第5回の記法と、この回の記法)。本文で、$Q_1$ を高温から受け取る熱、$Q_2$ を低温に捨てる熱として、区別を書きました。
  3. (a) の図(p.7):板書は、$Q_1\lt Q_1'$、$Q_2\gt Q_2'$(「これはダメ」)と書き、$Q_1=Q_1'$、$Q_2=Q_2'$ を結論しているように読めます。本文では、$Q_1\lt Q_1'$ のとき、$Q_2\lt Q_2'$(同じ $W$ なので)となる、と計算し直して、Clausius の原理に反することを示しました。
  4. $f(x,y)=F(x)G(y)$ の仮定(p.7):板書は変数分離型を仮定しています。補足の枠で、仮定しなくても、関係式から導けることを書きました。
  5. 氷点と沸点の記述(p.7):板書の「1気圧の氷点(融点)・沸点」と「$\dfrac{Q_2}{Q_1}=\dfrac{T_0}{T_0+100}$」は、図の読み取りが難しい箇所があります。「氷点の熱力学温度 $T_0$、沸点 $T_0+100$」と読みました。
  6. 「熱力学温度の非負性」の行(p.7):「$\therefore T_1=T_2$」のようにも見える箇所は、「$T_1\gt T_2$、$T_1\gt0$」の意味と読みました。
  7. 最後の「Clausius の不等式」の小節(Carnot サイクルの換算熱、熱源が2つ以上のとき)は、次の p.8 の内容(第7回)への導入です。第7回で、一般の場合を扱います。
