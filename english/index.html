Session 14:Igwes

教科書 p.112〜118 の要約と単語集(本文は掲載していません)。→ ワークシートの解答解説。固有名詞:Igbo=イボ族、igwe=イボ語で「王」、Nollywood=ナイジェリアの映画産業。単語を押すと意味が出ます。

— p.112 —

映画では、共和制や村の民主制がほとんど描かれず、いつも長老会議に囲まれた王(イグウェ)が出てくる。実際のイボ社会は、王を知らなかったわけではないが、ふつうは王をもたず、望みもしなかった。例として、アチェベの小説『崩れゆく絆』では、村に王はおらず、高い称号をもつ人々・祭司・長老が治め、一万人の自由人が集まって戦争の可否を討議する。

イギリス人は、自国の君主制や貴族制には無頓着なまま、民主的なアフリカ社会を理解できず、受け入れられなかった。植民地支配はもともと反民主的で、現地のイギリス人も少なかったので、従順な現地の首長を通す「間接統治」が必要だった。イボランドには首長がいなかったため、イギリスが「令状首長」を作り出した。多くは社会の最下層から選ばれ、協力と腐敗のために憎まれた。

植民地期以降、「伝統的支配者」は、政府と地域共同体をつなぐ仲介役として公認・創設され、1970年代以降に数も存在感も増した。「にせもの」という印象もしだいに薄れた。しかしアチェベは、1983年の著書でこれを厳しく批判した。

問い:なぜ映画では、イグウェが共和制と村の民主制の記憶を押しのけてしまったのか。

displace

映画では、民主制は、イグウェが即位するまでの「ほんの一瞬」の長老会議としてしか出てこない。『ペスティレンス』は、王も制度もない無秩序な状態から始まり、『カサラマ』では、呪医が「イグウェのない共同体は奴隷の土地のようなものだ」と長老をとがめる。君主制のほうが強く、あるべき形だと思われている。

install anomic dibia reproach normative

理由1:ヨルバの「カビイェシ映画」という身近な手本と、国家規模の政治的・文化的な枠組み。イギリスがインドの例にならって持ち込んだ、伝統的支配者の大儀式(ダルバール)、1950年代に各地域が作った「首長院」、民族文化の祭典 FESTAC など、「伝統的支配者を見せる」ことが権威の一部になった。ラーキンによれば、即位式を撮影させることは北部の支配者の権威づけの一部になり、いまもテレビの定番である。

— p.116 —

理由2:映画づくりの都合。君主の決定は、民主制の長い話し合いや、氏族の分散した仕組みよりも描きやすい。一人の英雄が動くハリウッド型にも合う。さらに、核家族の感情(きょうだいや共同妻の嫉妬、親が認めない恋愛、わがままな子、迫害される子)を、王室に映せるので、メロドラマの舞台に向いている。

アズオニエの見解:イボ人は「王の威厳(王権)」は大切にするが、「一人や一家が権力を独占する君主制」は忌み嫌う。ことわざ「Igbo enwe eze」は、「イボ人には王がいない」というより、「イボ人は君主の権力を嫌う」と訳すのがよい。

royalty majesty embodiment sovereign cherish anathema abhor

理由3(核心):イボ人の男はみな自分が王になりたいので、他人が王であることに耐えられず、現実では王を退けた。一方、称号は昔から熱心に求められ、バスデンは1921年に、すべての自由人の若者に首長への道が開かれていると述べた。現実と映画の関係を、「みんなが王になりたい」という一つの動機で効率よく説明できる。

— p.118 —

イボの称号は、威信は示すが、ヨルバやヨーロッパの称号のような実際の権力や領地を伴わない。数に上限がなく、お金で売買もされ(「金で買った首長」)、イギリス人が来る前からあった。通りに首長が30人もいるほどで、価値は下がっている。共和制のもとでは、称号は王とは別に存在したが、映画では、称号への欲望のすべてが、玉座の全能の一人に集約される。
